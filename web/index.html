Connect Spotify

Aurora reads what you are playing through your own Spotify app. It takes about a minute to set up, once.

  1. 1
    Open the Spotify developer dashboard and click Create app. Any name and description will do.
  2. 2
    Set the Redirect URI to exactly this, then tick the Web API checkbox:
    http://127.0.0.1:8888/callback
  3. 3
    Open the app Settings, copy the Client ID, and paste it below.
